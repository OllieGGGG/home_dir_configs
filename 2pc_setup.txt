If you want to use multiple PC's and want to share you mouse and keyboard
you can use input-leap utility.

Configuration file for server:
```
# +-------+  +--------+
# |Laptop |  |Desktop1|
# |       |  |        |
# +-------+  +--------+

section: screens
        Laptop:
        Desktop:
end

section: links
        Desktop:
                left  = Laptop
        Laptop:
                right = Desktop
end
```

Run server with:
```
input-leaps --address 0.0.0.0:9988 --config <config-name> --name Desktop --disable-crypto --no-daemon --no-tray
```

Run client with:
```
input-leapc --name Laptop --disable-crypto --no-daemon <server-host>:9988
```
